### **<font color='red'>一、WSL2安装与卸载</font>**

#### **<font color='#10c300'>1-1、安装WSL</font>**

##### **<font color='cornflowerblue'>一键安装（推荐）</font>**

```bash
wsl --install
```

此命令会自动完成：
- 启用必要的 Windows 功能
- 安装最新的 Linux 内核
- **默认安装 Ubuntu 发行版**

**安装完成后需要重启计算机**

![image-20260120235112242](https://picgo-2024.oss-cn-beijing.aliyuncs.com/img/image-20260120235112242.png)

<br>

#### **<font color='#10c300'>1-2、WSL常用命令</font>**

| 命令 | 说明 |
| :--- | :--- |
| `wsl` | 启动默认发行版 |
| `wsl --list --online` | 查看可安装的发行版 |
| `wsl --list` | 查看已安装的发行版名称 |
| `wsl --list --verbose` | 显示已安装的发行版名称、运行状态和WSL版本 |
| `wsl -d Ubuntu-22.04` | 启动指定发行版 |
| `wsl --shutdown` | 关闭所有正在运行的发行版 |
| `wsl --update` | 更新 WSL |
| `wsl --version` | 查看 WSL 版本 |
| `wsl --set-default Ubuntu-22.04` | 设置默认发行版 |
| `wsl --set-version Ubuntu-22.04 2` | 转换发行版版本（WSL 1 ↔ WSL 2） |

<br>

#### **<font color='#10c300'>1-4、注意事项</font>**

- 安装 WSL 需要管理员权限
- 卸载发行版会**完全删除**所有数据，卸载前请备份
- WSL 2 性能更好，推荐使用

<br>

#### **<font color='#10c300'>1-4、常见问题排查</font>**

##### **<font color='cornflowerblue'>❌ 问题1：计算机不支持WSL2</font>**

![image-20260123111656607](https://picgo-2024.oss-cn-beijing.aliyuncs.com/img/image-20260123111656607.png)

在powershell下输入wsl -l -v 也不显示版本

首先确保Hyper-v和适用于linux的windows子系统以及虚拟机平台是开启的

![image-20260123111934330](https://picgo-2024.oss-cn-beijing.aliyuncs.com/img/image-20260123111934330.png)

如果这些都没问题，在powershell（管理员模式）下输入如下命令

```bash
bcdedit /enum | findstr -i hypervisorlaunchtype
```

应该会显示off，那就说明有问题，那就再输入

```bash
bcdedit /set hypervisorlaunchtype Auto
```

即可解决

### **<font color='red'>二、安装AlmaLinux-9系统</font>**

一般企业服务器都是用的**`CentOS Linux`**系统，由于其2021 年底终止更新，于是乎企业环境中出现了**CentOS 替代方案** `Rocky Linux`、`AlmaLinux`等等

#### **<span style='color:#10c300'>2-1、AlmaLinux-9包管理工具</span>**

默认使用 **dnf（Dandified Yum）**，
它是 **yum 的下一代版本**，在语法上几乎完全兼容 `yum`。

换句话说：

> 在 AlmaLinux-9 上，`yum` 命令仍然可以用，但底层实际上调用的就是 `dnf`。

#### **<font color='#10c300'>2-2、卸载Ubuntu Server </font>**

在 **PowerShell（管理员）**中执行：

**1️⃣ 查看已安装的发行版**

```powershell
wsl --list --verbose
```

**2️⃣ 注销并卸载（特定发行版）**

```powershell
wsl --unregister Ubuntu
```

根据你安装的具体发行版名称，例如：

```powershell
wsl --unregister Ubuntu-22.04
wsl --unregister Debian
```

⚠️ **注意**：这会删除该发行版的所有数据！

<br>

**<font color='cornflowerblue'>验证卸载</font>**

```powershell
# 检查是否还有发行版
wsl --list

# 查看 WSL 版本
wsl --version
```

如果显示为空或报错，说明卸载成功。

#### **<span style='color:#10c300'>2-3、开始安装</span>**

在 PowerShell 中执行：

```powershell
wsl --install AlmaLinux-9
```

**安装过程：**
- 系统会开始下载AlmaLinux镜像（文件较大，请耐心等待）
- 显示进度条：`正在下载: AlmaLinux OS 9 [====70.3%====]`
- 下载完成后开始安装
- 安装完成后会显示：`已成功安装分发。可以通过 "wsl.exe -d AlmaLinux-9" 启动它`

#### **<span style='color:#10c300'>2-4、安装完成标志</span>**

```

已成功安装分发。可以通过 "wsl.exe -d AlmaLinux-9" 启动它
正在启动 AlmaLinux-9...
Please create a default UNIX user account.
Enter new UNIX username:
```

#### **<span style='color:#10c300'>2-5、初始化系统</span>**

##### **<span style='color:cornflowerblue'>第一步：启动AlmaLinux</span>**

```powershell
wsl -d AlmaLinux-9
```

##### **<span style='color:cornflowerblue'>第二步：创建UNIX用户账户</span>**

系统会提示输入以下信息：


### **<font color='red'>三、WSL2基础操作</font>**

#### **<font color='#10c300'>3-1、查看IP地址</font>**

##### **<font color='cornflowerblue'>方法一：使用 `ip` 命令</font>**

```bash
ip addr show eth0
简写
ip a
```

<br>

##### **<font color='cornflowerblue'>方法二：使用 `hostname` 命令（推荐）</font>**

```bash
hostname -I
```

<br>

##### **<font color='cornflowerblue'>方法三：使用 `ifconfig` 命令</font>**

```bash
ifconfig eth0
```

*注意：此方法需要先安装 `net-tools`*

```bash
sudo dnf install net-tools
```

**卸载某个软件包：**

```bash
# 卸载指定软件包，但保留配置文件和数据文件
sudo dnf remove net-tools

# 将配置文件一起删除，彻底清除，之后 `ifconfig` 命令就完全不能使用了
sudo dnf remove net-tools
```

<br>

##### **<font color='cornflowerblue'>关于 IP 地址说明</font>**

- **eth0**: WSL2 虚拟网络接口，通常在 `172.x.x.x` 段
- **lo**: 本地回环地址 `127.0.0.1`

**示例输出：**
```bash
$ hostname -I
172.24.240.100
```

这个 IP 地址可以用于从 Windows 访问 WSL2 中的服务

<br>

#### **<font color='#10c300'>3-2、查看用户信息</font>**

##### **<font color='cornflowerblue'>查看用户信息</font>**

**查看当前用户**
```bash
whoami
```

**查看所有用户**
```bash
cat /etc/passwd
```

**查看所有普通用户（UID >= 1000）**
```bash
awk -F: '$3 >= 1000 {print $1}' /etc/passwd
```

**查看当前登录用户的详细信息**
```bash
id
# 或
finger $(whoami)  # 需要安装 finger
```

<br>

##### **<font color='cornflowerblue'>密码管理</font>**

**⚠️ 重要说明**
**无法直接查看密码**，因为密码是加密存储的，在 `/etc/shadow` 文件中

**查看密码状态**
```bash
sudo passwd -S username
```

会显示状态：
- `P` = 已设置密码
- `NP` = 未设置密码
- `L` = 账户被锁定

<br>

##### **<font color='cornflowerblue'>设置/修改密码</font>**

**修改当前用户密码**
```bash
passwd
```

**修改其他用户密码（需要 root 权限）**
```bash
sudo passwd username
```

**从 Windows 重置 WSL 用户密码**

如果忘记了密码，可以在 **PowerShell** 或 **CMD** 中执行：

```powershell
# 1. 以 root 为默认用户
wsl -u root

# 2. 在 WSL 中重置密码
passwd your_username

# 3. 退出并恢复默认用户（可选）
# 编辑 /etc/wsl.conf 来使用默认用户
exit
```

或者一条命令：
```powershell
wsl -u root passwd your_username
```

<br>

##### **<font color='cornflowerblue'>查看 sudo 权限用户</font>**

```bash
# 查看 sudo 组成员
getent group sudo

# 或
grep '^sudo:' /etc/group
```

<br>

##### **<font color='cornflowerblue'>管理用户和权限</font>**

```bash
# 创建新用户
sudo adduser newuser

# 删除用户
sudo deluser username

# 将用户添加到 sudo 组
sudo usermod -aG sudo username
```

**提示**：WSL2 首次安装时需要你创建用户和密码，如果忘记需要重置用户账号。

### **<font color='red'>四、使用FinalShell连接WSL2</font>**

#### **<font color='#10c300'>4-1、连接原理</font>**

WSL2 默认**没有开启 SSH 服务**，需要手动安装和配置。

<br>

#### **<font color='#10c300'>4-2、安装和配置SSH服务</font>**

##### **<font color='cornflowerblue'>1️⃣ 在 WSL2 中安装 SSH 服务</font>**

```bash
# 更新软件包列表
sudo dnf update

# 安装 OpenSSH 服务器
sudo dnf install openssh-server -y
```

<br>

##### **<font color='cornflowerblue'>2️⃣ 配置 SSH 服务</font>**

```bash
# 编辑 SSH 配置文件
sudo nano /etc/ssh/sshd_config
```

**修改以下配置项**（使用 `Ctrl+W` 搜索）：

```bash
Port 22                          # 确认端口
PermitRootLogin no               # 禁止 root 登录（推荐）
PasswordAuthentication yes       # 启用密码认证
```

**保存**：
按 `Ctrl + O`(屏幕底部会提示 `File Name to Write:`)
然后按 **Enter** 确认保存。

**退出**：
按 `Ctrl + X`。

<br>

##### **<font color='cornflowerblue'>3️⃣ 启动 SSH 服务</font>**

```bash
# 启动 SSH 服务
sudo service ssh start

# 检查 SSH 服务状态
sudo service ssh status
```

如果看到以下输出，说明 SSH 服务已成功启动：

```
Active: active (running) since Sat 2026-01-17 19:50:01 CST; 4s ago
```

**状态是 `active (running)`**，说明服务正在运行。

关键信息：

```
Server listening on 0.0.0.0 port 22.
Server listening on :: port 22.
```

**SSH 服务正在监听 22 端口**，可以接受连接了。

<br>

##### **<font color='cornflowerblue'>4️⃣ 设置 SSH 自动启动（可选）</font>**

每次启动 WSL2 时自动启动 SSH：

```bash
# 编辑或创建 /etc/wsl.conf
sudo nano /etc/wsl.conf
```

添加以下内容：
```ini
[boot]
command="service ssh start"
```

<br>

##### **<font color='cornflowerblue'>5️⃣ 获取 WSL2 的 IP 地址</font>**

```bash
hostname -I
```

记录这个 IP，例如：`172.24.240.100`

<br>

##### **<font color='cornflowerblue'>6️⃣ 在 FinalShell 中创建连接</font>**

1. **打开 FinalShell**
2. **新建连接** → 选择 **SSH**
3. 填写信息：
   - **名称**：WSL2-Ubuntu（自定义）
   - **主机**：`172.x.x.x`（你的 WSL2 IP）
   - **端口**：`22`
   - **认证方式**：密码
   - **用户名**：你的 WSL2 用户名
   - **密码**：你的 WSL2 密码

4. **保存并连接**

<br>

#### **<font color='#10c300'>4-3、常见问题排查</font>**

##### **<font color='cornflowerblue'>❌ 问题1：连接超时</font>**

```bash
# 检查 SSH 是否运行
sudo service ssh status

# 如果没有运行，启动服务
sudo service ssh start
```

<br>

##### **<font color='cornflowerblue'>❌ 问题2：端口被占用</font>**

```bash
# 检查 22 端口是否占用
sudo netstat -tlnp | grep :22

# 如果使用其他端口，如 2222
sudo nano /etc/ssh/sshd_config
# 修改 Port 为 2222
sudo service ssh restart
```

<br>

##### **<font color='cornflowerblue'>❌ 问题3：防火墙阻拦</font>**

```bash
# 查看防火墙状态
sudo ufw status

# 如果已启用，允许 SSH
sudo ufw allow 22/tcp
```

<br>

##### **<font color='cornflowerblue'>❌ 问题4：IP 地址变化</font>**

**问题原因：**

WSL2 使用虚拟网络适配器，每次重启 WSL2 或 Windows 时，WSL2 的 IP 地址可能会发生变化（例如从 `172.17.114.127` 变成 `172.24.240.100`）。这会导致 FinalShell 中保存的连接配置失效，需要频繁更新 IP 地址。

**解决方案A：使用 localhost + 端口转发（推荐）**

通过 Windows 的端口转发功能，将 Windows 的某个端口映射到 WSL2 的 SSH 端口，这样无论 WSL2 的 IP 如何变化，都可以通过 `localhost` 连接。

**步骤：**

1. **获取当前 WSL2 的 IP 地址**
```bash
# 在 WSL2 中执行
hostname -I
```

2. **在 Windows PowerShell（管理员）中配置端口转发**
```powershell
# 将 Windows 的 2222 端口转发到 WSL2 的 22 端口
# 注意：需要替换 172.x.x.x 为实际的 WSL2 IP
netsh interface portproxy add v4tov4 listenport=2222 listenaddress=0.0.0.0 connectport=22 connectaddress=172.x.x.x
```

3. **在 FinalShell 中使用固定地址连接**
   - **主机**：`localhost` 或 `127.0.0.1`
   - **端口**：`2222`

**⚠️ 注意：**每次 WSL2 IP 变化后，需要重新执行端口转发命令。可以创建一个 PowerShell 脚本自动获取 IP 并配置转发。

**解决方案B：使用 Windows Terminal（最简单）**

Windows Terminal 是 Windows 10/11 自带的终端工具，可以直接启动 WSL2，无需 SSH 连接。

**优点：**
- ✅ 无需配置 SSH
- ✅ 无需担心 IP 变化
- ✅ 启动速度快
- ✅ 集成度高

**使用方法：**
1. 打开 **Windows Terminal**
2. 点击下拉箭头，选择 **Ubuntu**（或你的发行版）
3. 直接使用，就像使用 SSH 客户端一样

**解决方案C：配置静态 IP（高级）**

可以配置 WSL2 使用固定 IP，但需要修改 Windows 和 WSL2 的网络配置，比较复杂，不推荐普通用户使用。

<br>

##### **<font color='cornflowerblue'>❌ 问题5：密码认证失败</font>**

```bash
# 确认密码认证已启用
grep "PasswordAuthentication" /etc/ssh/sshd_config

# 重置密码
passwd

# 重启 SSH 服务
sudo service ssh restart
```

#### **<font color='#10c300'>4-4、快速测试连接</font>**

在 **Windows CMD** 或 **PowerShell** 中测试：
```bash
ssh your_username@172.x.x.x
```

如果能够连接，说明 SSH 配置正确，FinalShell 也应该能连接。

**SSH 连接格式说明：**
```bash

ssh 用户名@IP地址 -p 端口号
```

示例：
```bash
ssh zheng_hb@172.17.114.127
ssh zheng_hb@172.17.114.127 -p 22
ssh root@192.168.1.100 -p 2222
```

### **<font color='red'>五、关于IP地址变化的详细说明</font>**

#### **<font color='#10c300'>5-1、为什么WSL2的IP地址会变化？</font>**

WSL2 使用虚拟网络适配器（Virtual Network Adapter）来创建独立的网络环境。每次：
- 重启 Windows
- 重启 WSL2（`wsl --shutdown` 后重新启动）
- Windows 网络适配器重置

WSL2 的虚拟网络可能会重新分配 IP 地址，导致 IP 地址发生变化。

**示例：**
- 第一次启动：`172.17.114.127`
- 重启后：`172.24.240.100`
- 再次重启：`172.18.56.89`

<br>

#### **<font color='#10c300'>5-2、IP地址变化的影响</font>**

**影响场景：**
- ❌ FinalShell 中保存的连接配置失效
- ❌ 需要频繁更新 IP 地址
- ❌ 如果使用 IP 地址访问 WSL2 中的服务（如 Web 服务器），需要重新配置

**不受影响：**
- ✅ Windows Terminal 直接启动 WSL2（不依赖 IP）
- ✅ 在 Windows 中通过 `localhost` 访问 WSL2 服务（Windows 会自动处理）

<br>

#### **<font color='#10c300'>5-3、推荐解决方案对比</font>**

| 方案 | 优点 | 缺点 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **Windows Terminal** | 无需配置、稳定可靠、启动快 | 界面相对简单 | 日常开发使用（最推荐） |
| **端口转发** | 可以使用 FinalShell 等专业工具 | 需要手动配置、IP变化后需重新配置 | 需要 FinalShell 的高级功能 |
| **静态IP** | IP 固定不变 | 配置复杂、容易出错 | 特殊需求场景 |

<br>

#### **<font color='#10c300'>5-4、自动端口转发脚本（可选）</font>**

如果你坚持使用 FinalShell，可以创建一个 PowerShell 脚本自动配置端口转发：

**创建脚本 `wsl-port-forward.ps1`：**
```powershell
# 获取 WSL2 IP 地址
$wslIp = (wsl hostname -I).Trim()

# 删除旧的端口转发规则
netsh interface portproxy delete v4tov4 listenport=2222 listenaddress=0.0.0.0

# 添加新的端口转发规则
netsh interface portproxy add v4tov4 listenport=2222 listenaddress=0.0.0.0 connectport=22 connectaddress=$wslIp

Write-Host "端口转发已配置: localhost:2222 -> $wslIp:22"
```

**使用方法：**
每次启动 WSL2 后，以管理员身份运行此脚本即可。

### **<font color='red'>六、总结</font>**

本指南涵盖了 WSL2 的安装、卸载、基础操作和远程连接配置，帮助你快速上手使用 WSL2 开发环境。

**主要功能：**
- ✅ WSL2 安装与卸载
- ✅ IP 地址查看
- ✅ 用户管理
- ✅ SSH 服务配置
- ✅ FinalShell 远程连接

**注意事项：**
- 安装和卸载操作需要管理员权限
- 卸载发行版会删除所有数据，请提前备份
- **WSL2 的 IP 地址可能会变化**：
  - **推荐方案**：直接使用 **Windows Terminal**，无需配置，稳定可靠
  - **备选方案**：使用端口转发 + FinalShell，但需要处理 IP 变化问题
